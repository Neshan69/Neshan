# project-overview.md

**Purpose:** Understand what the product is, its current form, and trajectory.
**When to use:** Session start, scoping new work, onboarding.

**Rules**
- Neshan Niroula = a dark, editorial personal portfolio SPA (React + Vite + Tailwind) for a UI/UX Designer & Systems Architect.
- It is the front-end of a future full-stack platform (CMS, auth, API, admin).
- Treat every change as a step toward an enterprise-grade, production-first app.

**Do**
- Read PROJECT.md, CONTEXT.md, and this folder's SKILLS.md first.
- Distinguish prototype code (hard-coded images, no backend) from production goals.

**Don't**
- Don't treat the current SPA as the final architecture — backend is planned.
- Don't add product features without checking project-roadmap.md.

**Checklist**
- [ ] Know the design language (dark, monochrome + cyan, Playfair/Inter).
- [ ] Know current stack vs target stack.
- [ ] Located the relevant skill before coding.

**References:** See PROJECT.md · CONTEXT.md · architecture.md · project-roadmap.md.
